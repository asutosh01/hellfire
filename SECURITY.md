# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability or privacy leak:
1. Do not open a public issue.
2. Report the vulnerability privately via GitHub Security Advisories or contact the repository maintainers directly.
3. Include reproduction steps, affected versions, and expected impact. We will acknowledge receipt within 48 hours.
